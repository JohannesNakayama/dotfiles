## What I do

- Initialize a Go project

I adhere by the following rules:

- Add the following development tools to the flake:
    - gopls
    - air
- Put the code for executables into a `cmd/` folder and library code into `internal/`.
- If the app has a Go backend and a frontend, put the frontend into a folder called `web`.


## When to use me

When you are asked to initialize a project with Go in the stack.
